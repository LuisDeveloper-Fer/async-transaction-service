# Dirección visual

La interfaz se rediseñó a partir de referencias de sitios financieros compartidas por el usuario: navegación horizontal, fondo claro, titulares grandes, amarillo cálido, ilustración editorial y formularios de producto. Los detalles JSON son desplegables; el estado de una operación se presenta en lenguaje claro.

Marca ficticia: **nexo**. No ofrece servicios financieros ni representa una entidad real. Los otros laboratorios usan identidades ficticias propias: mora, enlace, cuadra, umbral y pulso.
